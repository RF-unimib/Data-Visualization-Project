## Project Overview

This repository contains the analysis and visualizations of factors influencing student academic performance.  
The aim of the project is to explore **relationships between socio-economic, behavioral, and educational variables** and students’ final performance outcomes.

The project focuses on identifying **patterns, correlations, and key drivers of performance**, with particular attention to:

- Study habits  
- Parental background  
- Attendance  
- Support factors  

The analysis demonstrates **data cleaning and preprocessing using R**, together with visualizations created through **raw R graphs, Flourish, and Tableau**, designed for **data-driven storytelling and exploratory data visualization**.
