Project Overview

This repository contains the analysis and visualizations of factors influencing student academic performance.
The aim of the project is to explore relationships between socio-economic, behavioral, and educational variables and students’ final performance outcomes.

The project focuses on identifying patterns, correlations, and key drivers of performance, with particular attention to study habits, parental background, attendance, and support factors.

The analysis demonstrates data cleaning, preprocessing using R, and visualization RAW graphs, Flourish and Tableau, with outputs designed for data-driven storytelling and exploratory data visualization.
